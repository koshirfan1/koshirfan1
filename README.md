## 📌 Featured Projects

### 🧬 [Kosh Programming Language](https://github.com/koshirfan1/Kosh)
A custom, indentation-based language built from scratch in **C11**: lexer, recursive-descent parser, bytecode compiler, and a stack-based VM. Ships with the `kh` package manager and 37 packages covering web (`webi`), computer vision, OCR, tensors/autograd, and networking.
**[▶ Try it in your browser](https://koshirfan1.github.io/Kosh/)** (compiled to WebAssembly)

### 📱 [KhanDroid](https://github.com/koshirfan1/KhanDroid)
**Kotlin** Android app for per-app, per-port traffic capture using `VpnService`. Features UDP/TCP forwarding, HTTP/HTTPS inspection, a live connections view, and PCAP export for Wireshark.

### ⬇️ [YT Downloader Pro](https://github.com/koshirfan1/yt-downloader-pro)
**Python** Tkinter desktop app for managing `yt-dlp` downloads: queues, quality/MP3 options, history search, plus a Chrome extension that sends the current tab to the app.
